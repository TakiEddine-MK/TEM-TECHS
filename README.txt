TEM TECHS — FINAL GODADDY RELEASE

READY TO HOST
1. Edit config.js first (email, phone, WhatsApp, social URLs, location, optional form endpoint).
2. In GoDaddy Web Hosting/cPanel, open File Manager.
3. Open public_html.
4. Upload ALL files and folders from this package directly into public_html.
5. index.html must be directly inside public_html.
6. Keep assets/ and services/ folders unchanged.
7. Visit your domain and test Home, service pages, EN/FR/DE, contact form, WhatsApp chat and social links.

CONTACT FORM
- If formEndpoint in config.js is blank, the form falls back to the visitor's email client.
- For direct website-to-email delivery, set formEndpoint to Formspree/Getform or a backend endpoint.
- WhatsApp works after you add your international number (digits only) in config.js.

SOCIAL LINKS
Add LinkedIn, Facebook, Instagram and X URLs in config.js. Until added, the icons remain visible but inactive.

DYNAMIC HOME
The homepage cycles through six local backgrounds every 3 seconds. Images are stored in assets/hero and do not depend on external image hosting.

BRANDING
The final wordmark is TEM TECHS / TECHNOLOGY with a white outlined circular T mark.

===================
This build keeps the approved TEM-Techs-Website-FINAL-GODADDY design and changes only:
